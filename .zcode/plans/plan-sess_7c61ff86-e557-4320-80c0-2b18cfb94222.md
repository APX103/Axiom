## 三层记忆系统

### 架构

一张 `memories` 表，三层用 `entity` 字段区分（和原工程一致）：

| 层 | entity | 生命周期 | 注入方式 |
|----|--------|----------|----------|
| Profile | `profile` | 永久，跨所有会话 | 每个会话的 system prompt 里完整注入 |
| Project | `project` | 永久，跨同项目会话 | 每轮按用户消息关键词 BM25 召回，注入到上下文 |
| Frame | `frame` | 会话级，删会话时清除 | 不自动注入，agent 通过 `read_memory("frame")` 主动读 |

### 改动清单

#### 后端

**1. `operon/db/schema.py` — 新增 memories 表**
```python
class MemoryRecord(Base):
    __tablename__ = "memories"
    id: str          # mem_<12hex>
    entity: str      # profile / project / frame
    body: str        # 记忆内容 (≤1000 字符)
    evidence: str    # stated / observed / inferred
    origin: str      # user / extractor
    frame_id: str | None  # frame 层用
    created_at / updated_at / last_surfaced_at
```

**2. `operon/memory/store.py` — 新建，记忆存储层**
- `MemoryStore`: CRUD + 搜索
- `list_by_entity(entity)` — 按层读
- `search(query, limit)` — BM25 搜索（纯 Python 实现，和原工程一样不用向量）
- `write(append/replace/remove)` — 写入，带 supersede 链
- `mark_surfaced(ids)` — 更新最后召回时间
- 用 SQLAlchemy async，和 ArtifactStore 同样的模式

**3. `operon/memory/recall.py` — 新建，召回引擎**
- `build_index(memories)` — 构建 BM25 索引（会话开始时）
- `recall(query, index, limit=6)` — BM25 + 关键词召回
- 纯 Python BM25 实现（~50 行），不需要外部依赖

**4. `operon/memory/extract.py` — 新建，记忆提取**
- `extract_memories(messages, existing_memories, llm)` — 每轮结束后后台调用
- 用 LLM 从本轮对话提取持久事实
- 返回 `{append, replace, remove}` 操作
- system prompt 用原工程的 `MEMORY_EXTRACT_PROMPT_SUFFIX` 逻辑

**5. `operon/tools/builtins/memory.py` — 新建，三个工具**
- `read_memory(entity)` — 读某层所有记忆
- `write_memory(append/replace/remove)` — 写入
- `search_memory(query)` — BM25 搜索全部记忆
- 注册到 `__init__.py`

**6. `operon/prompts/registry.py` — 加 RULES_MEMORY**
- 迁移原工程的 `vtO` (RULES_MEMORY) 规则文本，适配 Axiom 工具集
- 描述三层实体、evidence 标签、什么时候该写记忆
- `build_system_prompt` 注入 Profile 记忆块

**7. `operon/agent/session.py` — 初始化记忆**
- `prepare()` 创建 `MemoryStore`，加载 profile 记忆到 system prompt
- 构建 BM25 索引，存到 `ctx`
- `ctx.memory_store` + `ctx.memory_index`

**8. `operon/agent/runner.py` — 召回 + 提取**
- 每轮调 LLM 前：用用户消息做关键词召回，注入 `[Memory]` 块
- 每轮结束后：后台调 `extract_memories`，异步写入

**9. `operon/tools/context.py` — 加 memory 字段**
- `memory_store: Any = None`
- `memory_index: Any = None`

**10. `operon/config.py` — 加 MemoryConfig**
- `enabled: bool = True`
- `extract_enabled: bool = True`
- `extract_max_per_run: int = 5`
- `recall_inject_max: int = 6`

**11. `operon/api/app.py` — 记忆管理端点（可选，后续做 UI）**
- `GET /api/memories?entity=profile` — 列出记忆
- `DELETE /api/memories/{id}` — 删除记忆
